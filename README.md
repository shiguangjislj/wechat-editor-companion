# 公众号排版与视频助手

这是一个用于微信公众号图文编辑器的Chrome扩展。它在编辑页提供可移动的悬浮面板，帮助你批量设置正文和小标题样式、统一处理文章图片，并把一批视频暂存在本机后逐条送入公众号原生上传页面。当前发布的是**v0.7.10验证版**，需要Chrome148或更高版本。

> 本项目尚未发布到Chrome网上应用店。图文样式在编辑器中生效后，还要使用公众号原生“保存”，重新打开文章检查；视频只有在公众号素材库中核验到，才算确认入库。

## 下载和安装

1. 在本项目的[下载目录](downloads/)找到`wechat-editor-extension-v0.7.10.zip`，点击文件名，再点击页面右上角的**Download raw file**下载。
2. 解压ZIP。解压后应看到一个含`manifest.json`和`src`文件夹的扩展目录。
3. 用Chrome打开`chrome://extensions/`，打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择第2步解压出的、**直接包含`manifest.json`**的文件夹。
5. 打开或刷新公众号图文编辑页（`mp.weixin.qq.com`），页面上会出现“排版助手”悬浮球。点击即可使用。

更新时下载新版本ZIP、解压到新文件夹，在`chrome://extensions/`移除旧验证版后加载新文件夹，再刷新公众号页面。更新前请先等正在暂存或上传的视频完成；已有队列是否保留取决于扩展是否被移除及浏览器数据是否被清理。

## 能做什么

| 功能 | 使用方式 |
| --- | --- |
| 批量排版文字 | 在原文章中调整正文和小标题的字号、颜色、背景色及对齐，并可撤销最近一次文字排版。 |
| 统一处理图片 | 选择文章中的图片，一次应用圆角、阴影、对齐或描边；可撤销当前页面最近一次图片处理。原图片地址和顺序不变。 |
| 视频队列 | 一次选择多段视频暂存在本机；到公众号原生“添加视频”页后逐条上传，返回页面时保留队列和状态，也可继续补加视频。 |
| 可移动面板 | 拖动悬浮球和面板，按需要调整面板大小。 |

视频标题默认取原文件名并去掉扩展名；默认使用微信生成的第1张推荐封面。**是否声明原创由你在公众号原生页面选择**。首次出现视频上传服务协议时，也由你阅读并勾选。每条视频需在微信原生页面点击“保存”；扩展会尝试在“素材库→视频”列表核验结果。没有匹配到的项目会显示“待核对”，可检查素材库后再决定是否重新上传。视频入库后，由你在文章中选择插入位置。

## 使用前要知道

- 只在公众号`mp.weixin.qq.com`的相应页面运行；需要登录你自己的公众号账号。本项目不是微信官方产品。
- 视频文件暂存在本机浏览器的扩展存储中，不发送到本项目的服务器。暂存期间请保持页面打开，直到所有文件显示“待上传”。卸载扩展或清除浏览器扩展数据会删除暂存文件。
- 图片样式的撤销记录只在当前页面有效。刷新页面或更新扩展后无法撤销刷新前的那一批；请先在测试文章验证效果。
- 公众号可能清洗部分图片CSS。请在微信原生保存后重新打开文章，并用手机预览检查。
- 目前本地自动化测试已通过；真实公众号中的大文件上传、批次连续入库及保存后的显示效果仍需继续验收。详见[技术与验证说明](docs/技术与验证说明.md)。

迭代概要见[产品日志](CHANGELOG.md)。开发者可运行`npm ci`和`npm test`。如果遇到问题，可在仓库的Issues中附上扩展版本、Chrome版本、操作步骤及报错文字；提交截图前请遮盖公众号账号和文章隐私内容。
